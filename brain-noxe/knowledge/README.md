## Comment on alimente (process)
1. Tu m'apportes une ressource **de qualité** (formation exportée, swipe, transcript, résultat de test).
2. Je la nettoie et la range dans le bon domaine avec le template [[note-knowledge]].
3. Je relie aux fichiers concernés (produits, client, angles créa…).
4. Quand tu poses une question, je **croise** ces ressources avec tes vrais chiffres.
